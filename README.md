Konga Order Automation Test – Selenium IDE

Project Overview

This project automates the end-to-end ordering flow on Konga.com for an existing customer using Selenium IDE (Firefox Extension).
The automation validates key user actions from login to checkout, including handling invalid card payment and verifying the displayed error message.

Test Scenario Covered
The automated test script performs the following steps:
1. Launch the Konga website
2. Sign in as an existing user (using test credentials)
3. Navigate to Computers and Accessories
4. Select the Laptop sub-category
5. Click on Apple MacBooks
6. Add a MacBook item to the cart
7. Proceed to checkout
8. Select a delivery address
9. Continue to payment
10. Choose Card Payment method
11. Enter invalid card details
12. Validate and print the error message displayed
13. Close the payment iFrame modal
14. Close the browser

Tools & Technologies Used
* Selenium IDE (Firefox Extension)
* Mozilla Firefox Browser
* Git & GitHub (Version Control)
